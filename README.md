# 🐍 Curso de Python de la A a la Z

## 📚 Descripción

Curso completo de Python en español, pensado para quienes empiezan desde cero y quieren avanzar progresivamente hasta adquirir los conocimientos necesarios para crear sus propios proyectos.

El curso está organizado en un único archivo `.md` (Markdown), por lo que puedes descargarlo, guardarlo y estudiarlo sin necesidad de conexión a Internet.

## 📖 Contenido del curso

El curso está compuesto por **24 módulos** que abarcan desde los fundamentos de Python hasta conceptos más avanzados de programación.

Aprenderás temas como:

- Instalación y configuración de Python.
- Variables y tipos de datos.
- Operadores.
- Cadenas de texto.
- Listas, tuplas, conjuntos y diccionarios.
- Condicionales.
- Bucles `for` y `while`.
- Funciones.
- Módulos y paquetes.
- Manejo de archivos.
- Excepciones y gestión de errores.
- Programación orientada a objetos (POO).
- Archivos JSON y CSV.
- Depuración de código.
- Pruebas de programas.
- Buenas prácticas de programación.

## 🚀 Proyectos finales

Para poner en práctica los conocimientos adquiridos, el curso incluye **5 proyectos finales** que permitirán aplicar los conceptos estudiados y desarrollar habilidades para resolver problemas reales mediante Python.

## 📝 Metodología de aprendizaje

Cada módulo incluye:

- **Explicaciones:** conceptos explicados de manera clara, detallada y desde diferentes perspectivas.
- **Ejemplos:** fragmentos de código variados que muestran cómo funciona cada concepto y cómo aplicarlo.
- **Ejercicios:** actividades prácticas de dificultad progresiva para reforzar lo aprendido.
- **Soluciones:** respuestas explicadas para comprobar los resultados y comprender los procedimientos.

El objetivo no es memorizar código, sino comprender cómo funciona Python y aprender a utilizarlo para resolver problemas.

## 📦 Material adicional

El curso también incluye apéndices de consulta:

- Chuleta rápida de Python.
- Errores comunes y cómo solucionarlos.
- Glosario de términos de programación.
- Plan de estudio recomendado.

## 🎯 Objetivo del curso

Al finalizar el curso, tendrás una base sólida de Python y los conocimientos necesarios para comenzar a desarrollar tus propios programas, automatizaciones y aplicaciones.

**No necesitas conocimientos previos de programación.** El contenido está diseñado para avanzar desde los conceptos más básicos hasta temas más avanzados.

## 🛠️ Requisitos

- Un ordenador.
- Python 3 instalado.
- Un editor de código, como Visual Studio Code.
- Ganas de aprender y practicar.

## 💡 Recomendaciones

- Estudia los módulos en orden.
- Escribe los ejemplos por tu cuenta.
- Intenta resolver los ejercicios antes de consultar las soluciones.
- Experimenta modificando los ejemplos.
- Practica constantemente.

La programación se aprende practicando.
